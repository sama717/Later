# LATER - Gaming Library & Discovery Platform

A modern, high-performance web application built for discovering games and managing your personal backlog. 

## 🚀 Features
- **Discovery:** Browse games with real-time search, category filtering, and sorting.
- **Personalized Library:** Track your progress with "Backlog" and "Played" statuses.
- **Responsive UI:** Built with TailwindCSS and Shadcn/UI for a seamless experience across all devices.
- **Performance:** Optimized with lazy-loading and suspense for fast page transitions.

## 🛠 Tech Stack
- **Framework:** React + TypeScript + React Router
- **Styling:** TailwindCSS + Lucide Icons
- **State Management:** Zustand
- **Backend/Auth:** Supabase
- **API:** RAWG Video Games Database
